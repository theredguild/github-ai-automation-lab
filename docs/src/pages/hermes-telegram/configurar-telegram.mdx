# Configurar el canal Telegram

Con el bot propio, el token privado y tu ID numérico disponibles, dejá la sesión de chat separada. Vamos a configurar el canal desde otra shell de `lab-agent`, dentro de `/workspace`.

Para abrirla, usá otra terminal del host:

```bash
docker exec -it lab-agent bash
```

Cuando estés dentro del agente, iniciá el asistente del gateway:

```bash
hermes gateway setup
```

Elegí **Telegram**, ingresá el token de BotFather y configurá **Allowed users** con tu ID numérico. Conservá configuración existente de modelo y proveedor. No uses un `@username` ni dejes acceso abierto a cualquiera.

La allowlist es la lista de usuarios que Hermes acepta para conversar con el agente por este canal. Comprobá que hayas puesto tu ID numérico personal, no el del bot ni el de un grupo. El token permite al gateway operar el bot y la lista restringe quién puede enviarle pedidos al agente. Son controles distintos.

Al terminar, comprobá que el wizard haya guardado Telegram y la lista de usuarios permitidos. Fijate también si dejó un gateway activo para no iniciar un duplicado en el siguiente paso. **No sigas si** no podés comprobar la allowlist o se perdió la configuración del proveedor.

Recordá dónde ocurre cada acción. Das de alta el bot y enviás mensajes en Telegram, mientras que configurás el canal en el wizard nativo de Hermes. No existe un equivalente de `gh` para estas pantallas. [Procedimiento independiente del taller](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram).

# Instalar Hermes con el instructor

**Dónde:** instructor y participante, shell de `lab-agent`, `/workspace`, usuario `node`. **Antes:** escritura del proyecto y perfil comprobada sin errores.

La instalación se hace en vivo siguiendo la [documentación oficial de instalación](https://hermes-agent.nousresearch.com/docs/getting-started/installation). El instructor revisa sus requisitos vigentes y ejecuta ese procedimiento dentro de esta instancia, no en el host ni en el runner. El Dockerfile no incorpora silenciosamente otra instalación.

Si repetís el taller sin instructor, seguí esa misma documentación usando `node`. No copies un instalador de otra versión ni supongas que la imagen ya contiene Hermes. No necesitás estudiar sus herramientas de instalación para el resto del taller.

**Comprobación:** el procedimiento oficial termina y el comando `hermes` queda disponible en esta shell según la comprobación de esa documentación. **No sigas si** la instalación falla o sólo quedó disponible en otro entorno. El siguiente paso usa el wizard real de Hermes, no una implementación del taller.

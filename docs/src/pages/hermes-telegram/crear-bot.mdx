# Crear el bot de Telegram

**Dónde:** participante, aplicación Telegram; sin comandos de host. **Antes:** conversación por terminal respondida y cuenta de Telegram propia.

1. Abrí el [@BotFather oficial](https://t.me/BotFather).
2. Enviá `/newbot` dentro de ese chat.
3. Elegí nombre y un username único terminado en `bot`.
4. Guardá el bot token en privado para ingresarlo en el wizard.
5. Obtené tu **ID numérico de usuario** mediante el procedimiento de la [guía de Telegram de Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram).

Un `@username` no es el ID numérico. El token identifica al bot y tampoco reemplaza el ID del usuario permitido.

**Comprobación:** BotFather confirma el bot y tenés token e ID propios disponibles sin publicarlos. **No sigas si** desconocés cuál bot creaste o no obtuviste el ID numérico. No compartas captura del token. [Referencia oficial de creación de bots](https://core.telegram.org/bots/features#creating-a-new-bot).

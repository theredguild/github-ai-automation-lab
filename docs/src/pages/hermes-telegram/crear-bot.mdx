# Crear el bot de Telegram

Si la conversación por terminal ya respondió, pasá a la aplicación Telegram con tu cuenta propia. En este paso no hay comandos para ejecutar en el host. Vamos a crear el bot y reunir los dos datos que te pedirá Hermes:

1. Abrí el [@BotFather oficial](https://t.me/BotFather).
2. Enviá `/newbot` dentro de ese chat.
3. Elegí nombre y un username único terminado en `bot`.
4. Guardá el bot token en privado para ingresarlo en el wizard.
5. Obtené tu **ID numérico de usuario** mediante el procedimiento de la [guía de Telegram de Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram).

Fijate en que sean dos datos distintos. Un `@username` no es el ID numérico. El token identifica al bot y tampoco reemplaza el ID del usuario permitido.

Antes de continuar, comprobá que BotFather haya confirmado el bot y que tengas tu token y tu ID disponibles en privado. **No sigas si** desconocés cuál bot creaste o no obtuviste el ID numérico. No compartas captura del token. [Referencia oficial de creación de bots](https://core.telegram.org/bots/features#creating-a-new-bot).

# Comprobar un mensaje en Telegram

Con un único gateway activo, el modelo probado y tu ID numérico autorizado, volvé a Telegram. Dejá visible la terminal del gateway de `lab-agent` para relacionar los mensajes con sus logs:

1. Abrí el chat privado del bot que creaste.
2. Pulsá **Start** y enviá `/help`.
3. Enviá `Respondé exactamente: Hermes conectado.` como mensaje, no como comando de shell.
4. Comprobá la respuesta desde tu usuario permitido y los mensajes del gateway.

Fijate en las dos respuestas por separado. `/help` comprueba una función del canal, pero no demuestra por sí solo que el proveedor pudo generar una respuesta. Esperá también la contestación al mensaje de prueba.

Cuando recibas la respuesta del modelo, buscá su relación con los logs del gateway. Eso comprueba Telegram en esta sesión, no una integración con GitHub. **No sigas si** sólo responde `/help` o aparece usuario no autorizado. Revisá gateway, token, usuario permitido, proveedor y logs en ese orden en [diagnóstico de Hermes](/opcional/diagnostico-hermes).

Conservá el perfil y la instancia. El próximo capítulo prepara un origen HTTP separado; Telegram no necesita ese túnel.

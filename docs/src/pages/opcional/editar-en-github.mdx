# Hacer el cambio desde GitHub

**Dónde:** GitHub, tu repo propio. **Antes:** Production desde `main` funciona y elegiste la alternativa web antes de editar localmente. No mezcles ambos métodos con cambios pendientes.

En el selector de branches, creá `development` desde `main`, o seleccioná esa rama si ya existe. Abrí `app/page.tsx`, pulsá el lápiz y cambiá el título visible por una frase que reconozcas. Confirmá el cambio en **development**, no en main.

Conservá esa rama para los siguientes ejercicios. No crees otro repo ni otro proyecto Vercel: el push web dispara Preview mediante la integración existente.

**Comprobación:** el archivo y commit nuevos están en `development`; `main` conserva el título anterior hasta el merge. Si sólo modificaste main, detenete antes de comparar entornos.

Para retomar más adelante comandos locales, conservá el árbol limpio y ejecutá la [sincronización de ambas ramas](/docker-runner/sincronizar-ramas) cuando el curso llegue a ese paso.

# Diagnóstico de Hermes y Telegram

Primero identificá qué falla. Puede ser el chat por terminal, el comando `/help` o la respuesta del modelo por Telegram. Mirá los logs de la sesión CLI o del gateway dentro de `lab-agent`, en `/workspace`, y usá el wizard para revisar la configuración privada. **No compartas secretos al pedir ayuda.**

Si el canal no responde, revisá gateway, token del bot, usuario autorizado, proveedor y logs, en ese orden. Esta tabla te ayuda a distinguir problemas que requieren correcciones diferentes:

| Síntoma | Qué revisar |
| --- | --- |
| Error 401 del proveedor | Credencial de OpenRouter, no token de Telegram |
| Error 429 o modelo sin endpoint | Cuota y disponibilidad de la entrada gratuita |
| Usuario no autorizado | Tu ID numérico en la allowlist, no @username |
| Dos gateways para el mismo bot | Conservar una sola instancia activa |
| Responde /help pero no el mensaje | Proveedor, modelo y logs del gateway |
| Chat CLI funciona pero bot no responde | Canal Telegram, token, allowlist y proceso gateway |

Si encontrás gateways duplicados, identificá la terminal de la instancia sobrante y detené sólo esa con `Ctrl+C`. **No mates procesos ajenos ni borres el perfil para empezar de cero.** Para ajustar la configuración, usá `hermes setup` para proveedor/modelo o `hermes gateway setup` para el canal, en la shell del agente, y conservá los otros valores. No arranques otro gateway si ya hay uno activo.

Un error de cuota no autoriza fallback pago. Verificá [límites de modelos gratuitos](https://openrouter.ai/docs/guides/routing/model-variants/free). La [guía oficial de Telegram](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram) detalla canal y usuarios permitidos.

Después de corregir el problema, comprobá que haya un único gateway activo y que responda tanto al comando del canal como al mensaje del modelo. **No sigas si** necesitás mostrar tokens para explicar el fallo o la allowlist no está limitada a tu usuario.

Volvé a [comprobar el mensaje](/hermes-telegram/comprobar-mensaje).

# Opciones y diagnósticos

Estas páginas no son pasos obligatorios del curso. Elegí sólo la que necesitás y usá su enlace de regreso. El botón Next del recorrido principal no te obliga a ejecutarlas.

| Caso | Página |
| --- | --- |
| Terminaste el capítulo 1 y querés mostrar la misma landing remota | [Demo de Codespaces](/opcional/codespaces) |
| Un repo existente ya sigue dependencias o builds | [Reparar artefactos versionados](/opcional/reparar-artefactos) |
| Preferís hacer el cambio visible desde GitHub | [Editar por la web](/opcional/editar-en-github) |
| Repo, build o Preview no aparecen en Vercel | [Diagnóstico de Vercel](/opcional/diagnostico-vercel) |
| Chat o Telegram no responden | [Diagnóstico de Hermes](/opcional/diagnostico-hermes) |
| La respuesta local, interna o pública falla | [Diagnóstico del túnel](/opcional/diagnostico-tunel) |
| La entrega no termina en comentario | [Diagnóstico de la review](/opcional/diagnostico-review) |
| Más adelante necesitás un hostname estable | [Túnel administrado](/opcional/tunel-administrado) |

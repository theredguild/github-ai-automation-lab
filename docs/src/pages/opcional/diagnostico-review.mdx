# Diagnosticar una review por última evidencia

Esta página es opcional. El recorrido principal vuelve a [leer y contrastar la review](/review/leer-review).

**Dónde:** navegador del PR y Recent Deliveries del hook nativo, terminal del gateway en `lab-agent`, `/workspace`; host en `lab` para health. **Antes:** repo/PR, hostname actual, GUID si existe y SHA solicitados identificados. No imprimas el perfil, secrets, PAT, body completo ni headers sensibles.

Tomá la **última evidencia que realmente tenés**, no la etapa que esperabas alcanzar:

| Última evidencia | Siguiente comprobación |
| --- | --- |
| No hay entrega | Hook activo de esta review, hostname actual, evento Pull requests seleccionado y transición nueva de etiqueta ai-review que produzca labeled |
| Error de red o firma | Túnel, gateway, path /webhooks/github-pr-review, TLS verificado y secret del gateway coincidente en ambos lados |
| Evento ignorado | Repo, head repo, base main, estado Open, no draft, acción labeled y etiqueta exacta ai-review |
| Accepted, sin lectura del PR | Modelo con herramientas, toolsets y sesión gh en lab-agent |
| No lee el diff | Repo fijo, acceso Contents Read y consulta inmutable de base SHA...head SHA; no sustituir por checkout |
| Respuesta generada, sin comentario | Acceso Pull requests Write y configuración deliver: github_comment con repo y PR fijados |
| Solicitud desactualizada | Base o head cambió; contrastar estado actual y solicitar un labeled nuevo, no revisar silenciosamente otro diff |

## Separar salud local, túnel y autenticación

Desde el **host**, cwd `lab`:

```bash
curl -i http://127.0.0.1:8644/health
curl -i https://TU_URL_PUBLICA/health
```

Usá hostname real. Local 200 y público fallando sitúan el problema después del listener. Ambos 200 no prueban HMAC, filtros, disponibilidad del modelo ni comentario. No uses `localhost` desde otro container como si fuera el host. Revisá si [lab-agent ya pertenece a red-taller](/review/conectar-agente) antes de repetir una conexión o recrear nada.

Para comprobar sesión de herramientas, entrá desde el host al container existente:

```bash
docker exec -it lab-agent bash
cd /workspace
gh auth status
```

No uses opciones que muestran tokens. Confirmá cuenta y origen de credencial; variables `GH_TOKEN`/`GITHUB_TOKEN` pueden prevalecer. No las imprimas ni borres a ciegas. Si falta permiso, volvé al [PAT mínimo del agente](/webhook/autenticar-agente), no agregues Administration, Issues o permisos de organización por reflejo.

Para un evento ignorado, compará Request con [los filtros nativos](/review/configurar-ruta). No muevas la selección al prompt para permitir que todos los eventos gasten tokens. Para el caso negativo, ausencia de comentario no demuestra ausencia de llamada: correlacioná hora, GUID, logs y uso del proveedor.

## Modelo y comentario son etapas distintas

Revisá disponibilidad, límites y soporte de herramientas del proveedor. La disponibilidad gratuita no está garantizada. **No cambies automáticamente a un modelo pago ni habilites facturación.** Un fallo de consulta debe producir un error explícito, no una revisión inventada.

`github_comment` publica la respuesta al destino fijado. No pidas al modelo que improvise publicación por API, no exportes su PAT y no copies credenciales al runner. Conservá repo, base/head y guardas contra solicitud desactualizada; las instrucciones no hacen atómica la entrega ni sustituyen aislamiento.

**Comprobación:** podés señalar capa del fallo y nueva evidencia concreta de recuperación, sin haber debilitado controles. **No sigas si** para avanzar tendrías que desactivar firma/filtros, ejecutar código del PR en el agente, revelar credenciales o contratar otro servicio. Conservá el error no sensible para trabajarlo con el instructor.

Volvé a [leer y contrastar la review](/review/leer-review). Si cambió un SHA, solicitá después [una review nueva del commit actual](/review/solicitar-nueva-review).

Referencias: [webhooks nativos de Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/webhooks), [modelos gratuitos en OpenRouter](https://openrouter.ai/docs/guides/routing/model-variants/free).

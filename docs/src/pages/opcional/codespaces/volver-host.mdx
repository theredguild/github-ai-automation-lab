# Detener la demo y volver al host

**Dónde:** terminal del Codespace, después GitHub, finalmente tu equipo. **Antes:** terminaste de reconocer la landing.

1. `Ctrl+C` detiene Next en su terminal.
2. En [tu lista de Codespaces](https://github.com/codespaces), elegí **Stop codespace** para esa instancia. No la borres por rutina.
3. Volvé a la terminal del **host**, carpeta `lab`.

Cerrar la pestaña no detiene el entorno remoto. La presencia de `.devcontainer/devcontainer.json` tampoco certifica Docker, runner, credenciales o gateway allí. El resto del taller sigue en host + containers.

**Comprobación:** la instancia está detenida y la terminal donde vas a seguir pertenece a tu equipo.

# Detener la demo y volver al host

Ya terminaste de reconocer la landing remota. Ahora vamos a detener la demo antes de volver a tu equipo. Empezá en la terminal del Codespace y seguí este orden:

1. `Ctrl+C` detiene Next en su terminal.
2. En [tu lista de Codespaces](https://github.com/codespaces), elegí **Stop codespace** para esa instancia. No la borres por rutina.
3. Volvé a la terminal del **host**, carpeta `lab`.

No alcanza con cerrar la pestaña, porque eso no detiene el entorno remoto. La presencia de `.devcontainer/devcontainer.json` tampoco certifica Docker, runner, credenciales o gateway allí. El resto del taller sigue en host + containers.

Antes de retomar, fijate que la instancia figure detenida y que la terminal donde vas a seguir pertenezca a tu equipo.

# Ver la landing en el Codespace

Con el checkout limpio en main, sincronizado y con ambos SHA iguales, seguí en la terminal del Codespace, en la raíz de tu repo propio. Vamos a abrir la landing. Esto sigue siendo una demo, no el entorno para los seis ejercicios.

Primero comprobá que tengas Node 22 y pnpm 10.20.0:

```bash
node --version
pnpm --version
```

Si esas herramientas están disponibles, instalá las dependencias respetando el lockfile y arrancá el servidor de desarrollo:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Abrí **Ports → 3000 → Open in Browser**. Si Next imprime otro puerto, usá ese puerto real y mantenelo **privado**.

Comprobá que reconocés la landing. Esa URL remota no es Production de Vercel ni un endpoint de webhook. Si faltan herramientas, acceso o permisos, omití la demo y volvé al host. No sustituyas la [autenticación heredada](https://docs.github.com/en/codespaces/reference/security-in-github-codespaces) con `gh auth login`, scopes o variables de tokens.

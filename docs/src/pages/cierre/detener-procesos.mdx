# Detener los procesos de práctica

Ahora vamos a detener lo que haya quedado en ejecución. Empezá en las terminales del gateway y del túnel, y después usá el host para los containers que correspondan. Los hooks de práctica ya deberían estar desactivados. Si todavía no pudiste hacerlo, cerrá igualmente la exposición local. No hace falta haber completado los ejercicios.

En las terminales donde se ejecutan gateway y cloudflared, presioná `Ctrl+C`. Detener el gateway también interrumpe Telegram. Cerrar sólo el túnel, en cambio, deja el gateway funcionando. Si quedó un servidor Next en el host, detenelo también con `Ctrl+C` en su terminal.

**Si no llegaste a usar Docker en este taller, omití todos los pasos de Docker de esta página.** Si app y agente siguen activos, ejecutá el bloque siguiente desde el host. Si sólo creaste uno de esos containers, usá sólo su nombre en `docker stop`. Si no creaste ninguno, omití esa línea. No crees recursos para poder ejecutar el cierre.

```bash
docker stop lab-app lab-agent
docker ps
```

También puede haber quedado abierto el container de exploración `herramientas`. Si es tu caso, volvé a su shell inicial y ejecutá `exit`. Si ya no tenés esa terminal, identificá tu instancia con `docker ps` y detené sólo esa desde el host con `docker stop herramientas`.

El runner efímero debería haber terminado después de su único job. Si interrumpís la práctica mientras todavía espera o ejecuta un job, detenelo con `Ctrl+C` en su terminal. Si tu instancia `lab-runner` sigue activa, detenela desde el host con `docker stop lab-runner`. En GitHub Actions, cancelá sólo la ejecución de la práctica si todavía figura pendiente o en curso, y revisá su registro. **No detengas otros containers ni ejecuciones del equipo.**

Detener `lab-app` y `lab-agent` no borra sus archivos ni el proyecto montado. No elimines por rutina `hermes-home`, porque conserva tu progreso y credenciales. Si querés reutilizar el perfil, podés arrancar su container. Eso no renueva tokens revocados ni garantiza que la URL del túnel siga vigente. Si vas a descartarlo, decidilo después de guardar lo necesario.

Si usaste Codespaces, elegí **Stop codespace** en [tu lista](https://github.com/codespaces). Cerrar la pestaña no lo detiene. Un Codespace detenido puede consumir almacenamiento; eliminá únicamente uno que ya no necesites y cuyo trabajo esté publicado.

Al terminar, comprobá que los procesos de la práctica hayan dejado de recibir trabajo. Si usaste Docker en el taller, `docker ps` no debe mostrar sus instancias en ejecución. Los resultados de GitHub y Vercel permanecen, porque detener containers no elimina el repo ni los deployments. En el paso siguiente vamos a retirar los accesos dedicados.

# Cerrar la práctica

**Antes:** terminaste la revisión humana, integraste la corrección y comprobaste Production. Si todavía estás investigando una entrega, retomá [leer la review](/review/leer-review).

GitHub relaciona cambios, ejecuciones y eventos. Vercel construye deployments; el runner ejecuta checks; el túnel transporta requests; Hermes interpreta la tarea y publica una respuesta. Una persona conserva la decisión de integrar.

<img src={systemMap} alt="Mapa del taller: GitHub conectado con Vercel, runner, túnel y agente de review" />

Diagrama del taller. No representa una ejecución certificada de nuestras cuentas.

Guardá los cambios útiles con commit y push. Después seguí el cierre: primero desactivar hooks, después detener procesos y finalmente revocar credenciales dedicadas. No borres por rutina el perfil que contiene tu progreso.

**Comprobación:** podés identificar tu repo, el PR integrado, el último SHA de `main` y su deployment de Production. [Empezar el cierre](/cierre/desactivar-hooks).

# Verificar cliente y daemon

Abrí una terminal Bash del host en la carpeta `lab`. Para seguir, necesitás tener instalado [Docker Desktop o Docker Engine](https://docs.docker.com/get-started/get-docker/) y haber iniciado su servicio.

Primero vamos a comprobar que sus dos partes se comuniquen. El cliente es el comando `docker` que usás en la terminal. El daemon es el servicio que crea imágenes y administra containers. Tener el comando instalado no alcanza si ese servicio no responde.

```bash
docker version
```

Buscá las secciones Client y Server. La siguiente salida es un ejemplo para reconocerlas, no una prueba de ejecución:

```text
Client: Docker Engine …
Server: Docker Engine …
```

Si no conecta al daemon, iniciá Docker Desktop/Engine. Reinstalar el cliente no resuelve un servicio detenido. No necesitás Docker dentro de Codespaces.

**No sigas si** falta Server o aparece un error de conexión al daemon.

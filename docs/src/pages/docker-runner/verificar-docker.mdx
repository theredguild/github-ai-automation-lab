# Verificar cliente y daemon

**Dónde:** host, terminal Bash en la carpeta `lab`. **Antes:** instalar [Docker Desktop o Docker Engine](https://docs.docker.com/get-started/get-docker/) e iniciar su servicio.

El cliente es el comando `docker` que usás en la terminal. El daemon es el servicio que crea imágenes y administra containers. Necesitás que ambos se comuniquen, no sólo tener el comando instalado.

```bash
docker version
```

Debe mostrar las secciones Client y Server. Ejemplo de salida, no prueba de ejecución:

```text
Client: Docker Engine …
Server: Docker Engine …
```

Si no conecta al daemon, iniciá Docker Desktop/Engine. Reinstalar el cliente no resuelve un servicio detenido. No necesitás Docker dentro de Codespaces.

**No sigas si** falta Server o aparece un error de conexión al daemon.

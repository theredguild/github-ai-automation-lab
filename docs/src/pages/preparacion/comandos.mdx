# Leer comandos y reconocer la terminal

**Dónde:** esta página explica cómo leer las instrucciones; todavía no creás containers.

Cada página indica dónde trabajar. Cuando diga **host**, se refiere a tu equipo o WSL2. Más adelante crearemos otros entornos y los identificaremos por nombre. No ejecutes un comando del host dentro de la shell de otro entorno.

La carpeta actual es el punto de partida de las rutas relativas. Si una instrucción menciona `app/page.tsx`, ese archivo se busca desde la carpeta donde estás. Una ruta que empieza con `/`, como `/workspace`, es absoluta y parte de la raíz del entorno donde se ejecuta el comando.

Para ver tu carpeta actual:

```bash
pwd
```

`cd` cambia de carpeta. `cd ..` sube a la carpeta que contiene la actual y `.` representa la carpeta actual. Cuando una página diga `cwd`, se refiere a esa carpeta. Cuando diga `branch`, se refiere a la rama de Git.

Algunos ejemplos usan marcadores como `TU_USUARIO/REPO` o `NUMERO`. Cuando la página indique reemplazarlos, escribí tus datos en su lugar. No cambies los nombres de variables como `WEBHOOK_SECRET`: la aplicación espera ese nombre exacto y vos configurás su valor.

| Valor | Qué reemplazás |
| --- | --- |
| `TU_USUARIO/REPO` | Propietario y nombre de tu repo, no del material |
| `NUMERO` | Número real del pull request, o PR, sin `#` |

Una línea terminada en `\` continúa en la siguiente. Pegá ese bloque completo. Las líneas que empiezan con `#` son comentarios.

Los bloques `text` muestran **ejemplos de salida** o **tareas para el agente**, según su rótulo. No son comandos de Bash. Los fragmentos de archivos se editan en el archivo indicado; no se pegan como comandos.

Cuando un proceso ocupa una terminal, dejala abierta y usá otra para el siguiente paso. `Ctrl+C` detiene ese proceso, no necesariamente el container, el túnel remoto o el Codespace.

**Antes de avanzar:** podés leer la carpeta actual con `pwd` y reconocer qué valores de un comando tendrías que reemplazar. Si la terminal o la carpeta no coinciden con la página, corregí eso antes de copiar comandos.

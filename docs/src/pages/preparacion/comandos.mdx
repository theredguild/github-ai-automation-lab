# Leer comandos y reconocer la terminal

Antes de empezar, vamos a ver cómo leer los comandos y reconocer en qué terminal estamos trabajando. Por ahora seguimos en tu equipo. Todavía no vamos a crear containers.

Cada página te va a indicar dónde trabajar. Cuando diga **host**, se refiere a tu equipo o WSL2. Más adelante vamos a crear otros entornos y los identificaremos por nombre. Si una página indica host, ejecutá el comando ahí, no en la shell de otro entorno.

También importa la carpeta donde estás. Si una instrucción menciona `app/page.tsx`, esa ruta se busca a partir de tu carpeta actual. A eso lo llamamos una ruta relativa. En cambio, una ruta que empieza con `/`, como `/workspace`, es absoluta y parte de la raíz del entorno donde ejecutás el comando.

Probá este comando para ver tu carpeta actual:

```bash
pwd
```

Para cambiar de carpeta usamos `cd`. Con `cd ..` subís a la carpeta que contiene la actual, mientras que `.` representa la carpeta actual. Si encontrás `cwd` en una página, se refiere a esa carpeta. Si encontrás `branch`, se refiere a la rama de Git.

En algunos ejemplos vas a ver marcadores como `TU_USUARIO/REPO` o `NUMERO`. Cuando la página te pida reemplazarlos, escribí tus datos en su lugar. No hagas lo mismo con nombres de variables como `WEBHOOK_SECRET`. La aplicación espera ese nombre exacto y vos configurás su valor.

| Valor | Qué reemplazás |
| --- | --- |
| `TU_USUARIO/REPO` | Propietario y nombre de tu repo, no del material |
| `NUMERO` | Número real del pull request, o PR, sin `#` |

Cuando una línea termina en `\`, el comando continúa en la siguiente. Pegá el bloque completo. Las líneas que empiezan con `#` son comentarios y no forman parte de lo que se ejecuta.

No todos los bloques son comandos para pegar en la terminal. Los que dicen `text` pueden mostrar una salida de ejemplo o una tarea para el agente, según su rótulo. Si ves un fragmento de un archivo, abrilo en el editor y hacé el cambio ahí.

Si un proceso queda ocupando una terminal, dejala abierta y usá otra para el paso siguiente. `Ctrl+C` detiene ese proceso, pero no necesariamente detiene también el container, el túnel remoto o el Codespace.

Antes de avanzar, fijate qué carpeta te muestra `pwd` y qué valores tendrías que reemplazar en un comando de ejemplo. Cuando copies instrucciones de otra página, comprobá que estés en la terminal y la carpeta que pide. Si no coinciden, corregí eso primero.

# Crear un único webhook de Next

**Dónde:** Hermes CLI en `lab-agent`, `/workspace`, o navegador del repo propio. Branch sin cambios. **Antes:** [receptor configurado](/webhook/preparar-receptor), túnel actual hacia `lab-app:3000`, hostname público real y secret privado de `.env.local`.

Elegí **una sola** forma. Un hook delegado y otro manual para la misma URL producen entregas duplicadas distintas; no prueban la deduplicación por GUID.

## Delegar a Hermes

Sólo si su PAT incluye Webhooks: Read and write, enviá esta tarea. No incluyas secretos en el mensaje:

```text
Configurá un único webhook en TU_USUARIO/REPO.
URL: https://TU_URL_PUBLICA/api/github
Usá el secret de .env.local sin mostrarlo.
Content type: application/json. Sólo Pull requests y TLS verificado.
No dupliques ni toques hooks de otros servicios.
No modifiques hooks ajenos ni permisos del repositorio.
Mostrá URL, eventos y estado, sin credenciales.
Indicá cómo encontrarlo y comprobarlo desde la web.
```

:::details[Alternativa web: crear el mismo hook sin delegar]
En tu repo abrí **Settings → Webhooks → Add webhook**:

1. **Payload URL:** `https://TU_URL_PUBLICA/api/github`, con hostname de tu túnel actual.
2. **Content type:** `application/json`.
3. **Secret:** el mismo valor privado configurado en `WEBHOOK_SECRET`.
4. **Let me select individual events → Pull requests** únicamente.
5. Conservá **SSL verification** habilitado, marcá **Active** y guardá.

El secret no es el bot token de Telegram ni la API key del modelo. No lo pegues en la URL.
:::

**Comprobación:** en **Settings → Webhooks** encontrás exactamente un hook de esta práctica, con hostname actual, path `/api/github`, JSON, Pull requests y TLS verificado. Identificá su ID y dónde ver sus entregas. No hace falta copiar una secuencia de PATCH a la API.

El `ping` inicial puede fallar mientras Next todavía no haya leído la configuración nueva. No reemplaza la prueba de PR. **No sigas si** creaste dos hooks equivalentes, usaste otro repo o deshabilitaste la verificación TLS. Corregí sólo el hook de tu práctica; no alteres servicios ajenos.

# Correlacionar la entrega con los logs

**Dónde:** navegador de tu repo y terminal de `lab-app` que muestra logs de Next, cwd `/workspace`. **Antes:** [PR actualizado o creado](/webhook/generar-evento), número y SHA reconocidos, túnel todavía activo.

Abrí **Settings → Webhooks → hook de /api/github → Recent Deliveries**. Seleccioná la entrega `pull_request` de tu cambio. Podés inspeccionar el `ping` inicial, pero éste sólo prueba el alta.

<img src={deliveries} alt="Recent Deliveries de GitHub permite abrir Request y Response de cada entrega" />

Captura de referencia del taller; usá los datos de tu entrega real, no los de la imagen.

Comprobá en orden:

1. URL usa el hostname actual del túnel y el path `/api/github`.
2. **Request** contiene `X-GitHub-Event: pull_request` y `X-GitHub-Delivery`. Anotá GUID, acción y número de PR sin copiar secretos ni body completo.
3. **Response** es 200 y el JSON indica `received` para este evento válido.
4. Log `github-webhook` de Next contiene el mismo delivery GUID, evento, acción, repo y número. El registro no incluye secret ni body completo.

La correlación de GUID y repo une ambos extremos. Un 200 de otro evento o un log anterior no es evidencia de esta entrega.

| Respuesta | Interpretación en este receptor |
| --- | --- |
| 200 received | Validó y reconoció el evento; no ejecutó IA |
| 200 ignored | Evento fuera del trabajo que atiende |
| 200 duplicate | Ya recuerda ese ID de entrega |
| 401 invalid_signature | Firma faltante o inválida; revisar secret y bytes originales |
| 403 repository_not_allowed | Repo distinto al configurado |
| 404 o error del gateway | Revisar path, túnel y proceso |
| 413 body_too_large | Body supera 128 KiB |
| 415 use_application_json | Content-Type no es application/json |
| 503 receiver_not_configured | Variables faltantes o inválidas; revisar configuración y reinicio |
| 400 | Body/JSON o delivery ID inválido; inspeccionar error concreto |

**Comprobación:** podés señalar una única entrega `pull_request` y su mismo GUID en respuesta y logs. **No sigas si** sólo encontrás ping, no coincide repo/GUID o necesitás eliminar firma o filtros para recibirla. Corregí la capa indicada por la respuesta, sin publicar datos privados.

Referencia: [ver entregas de GitHub](https://docs.github.com/en/webhooks/testing-and-troubleshooting-webhooks/viewing-webhook-deliveries).

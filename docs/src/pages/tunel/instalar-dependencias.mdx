# Instalar dependencias en lab-app

**Dónde:** shell interactiva de `lab-app`, `/workspace`, rama montada `development`. **Antes:** proyecto correcto montado y lockfile presente.

```bash
pnpm install --frozen-lockfile
```

Si pnpm detecta un `node_modules` creado antes en el host u otro container, puede pedir permiso para recrearlo con el store actual. En esta terminal interactiva aceptá sólo para el proyecto de la práctica y esperá a que termine.

Cada instancia conserva su propio cache del store fuera del bind mount. No borres el lockfile ni edites dependencias para resolver esa pregunta. La carpeta de dependencias montada puede cambiar para ajustarse a este entorno.

**Comprobación:** instalación termina sin error y vuelve la shell. **No sigas si** el lockfile no coincide, falló una descarga o la pregunta menciona un proyecto distinto.

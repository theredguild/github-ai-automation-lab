# Instalar dependencias en lab-app

Seguimos en la shell interactiva de `lab-app`, en `/workspace`, con la rama `development` montada desde el host. Comprobá que sea el proyecto correcto y que tenga su lockfile. Vamos a instalar las dependencias respetando ese archivo:

```bash
pnpm install --frozen-lockfile
```

Si pnpm detecta un `node_modules` creado antes en el host u otro container, puede pedir permiso para recrearlo con el store actual. En esta terminal interactiva aceptá sólo para el proyecto de la práctica y esperá a que termine.

Cada instancia conserva su propio cache del store fuera del bind mount. La carpeta de dependencias montada puede cambiar para ajustarse a este entorno. No borres el lockfile ni edites dependencias para responder esa pregunta.

Esperá a que la instalación termine sin error y vuelva la shell. **No sigas si** el lockfile no coincide, falló una descarga o la pregunta menciona un proyecto distinto.

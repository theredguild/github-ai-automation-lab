# Iniciar Git y revisar identidad

**Dónde:** host, `lab`, junto a `package.json` y `Dockerfile`. **Antes:** ruta y estructura verificadas, app sin inicializar y login comprobado. Todavía no instalaste dependencias. El starter ya trae `.gitignore`.

`git init -b main` crea el repositorio local en una carpeta oculta `.git` y nombra `main` a la rama inicial. Ahí Git guardará el historial. Los archivos que editás en `lab` forman la copia de trabajo o working tree; todavía no hay un commit ni conexión con el repo de GitHub.

```bash
git init -b main
git config user.name
git config user.email
```

Nombre y email del commit son distintos del login de GitHub. Si faltan o pertenecen a otra persona, configurá sólo este repo con tus datos reales:

```bash
git config user.name "Tu nombre"
git config user.email "TU_EMAIL"
```

Repetí las consultas para verificar el valor. Comprobá la rama:

```bash
git branch --show-current
```

Debe mostrar `main`. La identidad se guarda localmente al omitir `--global`.

**No sigas si** estás en el material, faltan los archivos de app o la identidad sigue siendo ajena.

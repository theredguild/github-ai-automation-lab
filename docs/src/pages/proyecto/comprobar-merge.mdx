# Comprobar Production después del merge

**Dónde:** navegador, PR GitHub y mismo proyecto Vercel. **Antes:** PR integrado con merge commit; conservaste `development`.

<img src={branches} alt="main avanza al merge mientras development conserva su referencia" />

Diagrama del taller; ejemplo conceptual. La branch es una referencia, no una copia independiente de todos los archivos.

Esperá el nuevo deployment de **Production** desde `main`. Comprobá **Ready**, rama, commit y URL. Abrí la landing y buscá tu título nuevo, por ejemplo "Aprender y construir en comunidad".

Compará el SHA con el commit que quedó en `main`. El merge puede tener un SHA distinto de la cabeza del PR; no compares Production contra el antiguo SHA de `development` como si fueran iguales.

Antes de seguir, identificá:

- Tu repo propio con `main` y `development`, archivos confirmados y enviados.
- El PR integrado y su commit de merge.
- La URL de Production y el deployment que muestra el título nuevo.
- La URL única del Preview que probaste y su SHA.
- El build local de Next.js que terminó sin errores.

**No sigas si** Production muestra otro commit o contenido. [Diagnóstico de Vercel](/opcional/diagnostico-vercel) orienta por repo no visible, framework no detectado, build fallido o cambio ausente; [reparación de artefactos](/opcional/reparar-artefactos) sólo aplica si ya estaban versionados.

### Trasladarlo a tu proyecto

Se conservan repo, branches, commits, PR, integración Git con Vercel y comparación Preview/Production. Se adaptan framework, directorio raíz, gestor, lockfile, comando de build y variables que realmente necesita la app. No cambies el recorrido de Git para compensar un ajuste del framework.

La [demo opcional de Codespaces](/opcional/codespaces) puede hacerse ahora, sólo para esta landing. Después volvés al host; no reemplaza el taller completo.

El siguiente capítulo, [Docker y runner](/docker-runner), usa esta misma app y `Dockerfile` para ejecutar un check propio. No confundas ese workflow con el estado de Vercel que ya comprobaste.

# Crear el primer commit

**Dónde:** host, `lab`, rama `main`. **Antes:** Git e identidad local configurados; todavía sin instalar dependencias. El `.gitignore` incluido ya protege archivos locales.

```bash
git add .
git status
```

Deben aparecer la app y su configuración: `app/`, `public/`, `package.json`, lockfile, `Dockerfile`, `.gitignore` y los demás archivos del starter. No deben aparecer guía, slides, dependencias, builds ni secretos.

**No sigas si** el índice contiene archivos del material, credenciales o artefactos generados. No confirmes una selección incorrecta.

Después de revisar:

```bash
git commit -m "Inicio del sitio"
git log -1 --oneline
```

Comprobá que el último commit tiene ese mensaje. Commit crea una versión local; todavía no publicó nada en GitHub.

# Instalar las dependencias

Ya comprobamos el primer push y las reglas de `.gitignore`. Ahora vamos a instalar lo que necesita la app. Seguí en Bash en el host, dentro de `lab` y en la rama `main`. Prepará [Node 22](https://nodejs.org/en/download) y [pnpm 10.20.0](https://pnpm.io/installation) en tu equipo, y consultá sus versiones:

```bash
node --version
pnpm --version
```

Ejemplo de versiones esperadas:

```text
v22.x.x
10.20.0
```

Con las versiones correctas, abrí `package.json` en el editor. Ahí vas a encontrar los scripts que usaremos para ejecutar y construir la app. Este fragmento es ilustrativo, no reemplaza el archivo:

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build"
  }
}
```

La landing ya existe y `pnpm-lock.yaml` fija sus dependencias. No ejecutes un generador para crear otra app.

Node ejecuta el código JavaScript. pnpm administra las dependencias y ejecuta los scripts de `package.json`. Al instalar, descarga en `node_modules/` las bibliotecas que necesita la app, pero todavía no construye ni abre el sitio. Vamos a usar `--frozen-lockfile` para respetar el lockfile. Si no coincide con `package.json`, el comando falla en vez de actualizarlo.

```bash
pnpm install --frozen-lockfile
```

Esperá a que termine sin errores y comprobá que usa pnpm 10.20.0. Podés ver un mensaje como `Lockfile is up to date`, pero es un ejemplo de salida, no una prueba de tu ejecución.

**No sigas si** faltan herramientas, sus versiones no coinciden o falla la instalación. No borres ni regeneres el lockfile para esconder el error. [Instalación de pnpm](https://pnpm.io/cli/install).

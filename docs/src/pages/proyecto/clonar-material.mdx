# Clonar el material

**Dónde:** host, en una terminal Bash de tu equipo o WSL2, dentro de la carpeta donde guardás proyectos. **Antes:** [Git](https://git-scm.com/install/), [GitHub CLI](https://cli.github.com/) y acceso de lectura al material ya resuelto con tu cuenta o credencial existente.

El material todavía es privado. El token limitado al sitio que crearás más adelante no permite leerlo. No reemplaces ahora una credencial que necesitás para este clone.

```bash
git clone https://github.com/theredguild/github-ai-automation-lab.git
cd github-ai-automation-lab
```

Comprobá en el editor que abriste el material y que contiene `hackerspace-site/`, guía y presentación. Este checkout no será el repositorio de tu aplicación.

**No sigas si** el clone o el `cd` falla. Resolvé el acceso antes de mover archivos; no publiques el material privado en otro repo.
